# Sistema Acadêmico ICSZ.IO — SIGA 2.0

## Sobre o projeto

O SIGA 2.0 é um sistema acadêmico desenvolvido para facilitar a gestão e o acompanhamento das atividades escolares, reunindo funcionalidades para diferentes perfis de usuários.

## Perfis do sistema
- **Administrador:** gerenciamento geral do sistema.
- **Secretaria:** organização e administração das informações acadêmicas.
- **Aluno:** acesso às informações e funcionalidades acadêmicas disponíveis.
- **Professor:** acesso às funcionalidades destinadas às atividades docentes.

## Tecnologias
- TypeScript
- CSS
- HTML
